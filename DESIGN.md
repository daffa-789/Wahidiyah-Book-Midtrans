# Design System

Dokumen ini hanya menjadi pengarah. **Master Memory Workflow** adalah satu-satunya memory teknis utama.

Gunakan [bagian design system di Master Memory Workflow](./Master_Memory_Workflow.md#4-spesifikasi-lengkap-design-system--standar-visual-ui) untuk prinsip visual, token tema, tata letak, tipografi, responsivitas, dan aksesibilitas. Implementasi token berada di src/lib/styles.js dan tema Tailwind.

Saat mengubah aturan desain, perbarui Master Memory Workflow; jangan menyalin spesifikasi ke file ini.
